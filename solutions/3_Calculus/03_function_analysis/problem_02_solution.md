## Question

For $f(x)=x^2-4x+1$, find the minimum using the derivative. Compare the result with the vertex form and explain why both approaches lead to the same point.

## Solution

Using the derivative:

$$
f'(x) = 2x - 4 = 0 \implies x = 2
$$

Since $f'(x) < 0$ for $x < 2$ and $f'(x) > 0$ for $x > 2$, $f$ attains its global minimum at $x = 2$ with $f(2) = 4 - 8 + 1 = -3$, point $(2, -3)$.

Using vertex form:

$$
f(x) = (x - 2)^2 - 3
$$

Since $(x - 2)^2 \ge 0$ with equality only at $x = 2$, the vertex is $(2, -3)$. Both locate the point where the tangent line is horizontal and the function stops decreasing and starts increasing.
