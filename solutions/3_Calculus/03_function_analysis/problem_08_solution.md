## Question

For

$$f(x)=x^4-4x^2$$

find the local extrema, intervals of convexity and concavity, and inflection points. Sketch the graph and mark all the identified features on it.

## Solution

First derivative:

$$f'(x) = 4x^3 - 8x = 4x(x^2 - 2) = 0 \implies x = 0, \ \pm\sqrt{2}$$

- Local maximum at $x = 0$: $f(0) = 0$.
- Local minima at $x = \pm\sqrt{2}$: $f(\pm\sqrt{2}) = 4 - 8 = -4$.

Second derivative:

$$f''(x) = 12x^2 - 8 = 4(3x^2 - 2) = 0 \implies x = \pm\sqrt{\frac{2}{3}}$$

- Convex ($f''(x) > 0$): $\left(-\infty, -\sqrt{\frac{2}{3}}\right)$ and $\left(\sqrt{\frac{2}{3}}, \infty\right)$.
- Concave ($f''(x) < 0$): $\left(-\sqrt{\frac{2}{3}}, \sqrt{\frac{2}{3}}\right)$.
- Inflection points: $\left(\pm\sqrt{\frac{2}{3}}, -\frac{20}{9}\right)$.
