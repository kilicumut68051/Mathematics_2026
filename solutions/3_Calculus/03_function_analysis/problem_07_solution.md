## Question

On $[0,2\pi]$, find the intervals of monotonicity and the extrema of

$$
f(x)=\sin x+\cos x.
$$

Include the endpoints of the interval and compare the function values at the critical points and at the endpoints.

## Solution

$$
f'(x) = \cos x - \sin x = 0 \implies \tan x = 1 \implies x = \frac{\pi}{4}, \ \frac{5\pi}{4} \in [0, 2\pi]
$$

- On $\left[0, \frac{\pi}{4}\right)$: $f'(x) > 0 \implies$ increasing.
- On $\left(\frac{\pi}{4}, \frac{5\pi}{4}\right)$: $f'(x) < 0 \implies$ decreasing.
- On $\left(\frac{5\pi}{4}, 2\pi\right]$: $f'(x) > 0 \implies$ increasing.

Values:
- Endpoints: $f(0) = 1$, $f(2\pi) = 1$.
- Local and global maximum at $x = \frac{\pi}{4}$: $f\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2} = \sqrt{2}$.
- Local and global minimum at $x = \frac{5\pi}{4}$: $f\left(\frac{5\pi}{4}\right) = -\frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2} = -\sqrt{2}$.
