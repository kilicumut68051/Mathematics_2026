## Question

For

$$f(x)=2\sqrt{x}-\frac{3}{x^2}+x^{3/2}$$

1. rewrite the function using powers,
2. determine the domain,
3. compute the derivative,
4. compare the domain of the function with the domain of its derivative.

## Solution

1. Power form:

$$f(x) = 2x^{1/2} - 3x^{-2} + x^{3/2}$$

2. Domain of $f$: $\sqrt{x}$ requires $x \ge 0$ and $x^{-2}$ requires $x \neq 0$, so $D_f = (0, \infty)$.

3. Derivative via power rule:

$$f'(x) = 2\cdot\frac{1}{2}x^{-1/2} - 3(-2)x^{-3} + \frac{3}{2}x^{1/2} = x^{-1/2} + 6x^{-3} + \frac{3}{2}x^{1/2} = \frac{1}{\sqrt{x}} + \frac{6}{x^3} + \frac{3}{2}\sqrt{x}$$

4. Domain comparison: $D_{f'} = (0, \infty)$, identical to $D_f$ (since $x^{-1/2}$ already requires $x > 0$).
