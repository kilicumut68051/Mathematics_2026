## Question

Exercise 1. Definition of the Inverse

For
A = [2, 1; 1, 1], B = [1, -1; -1, 2]
check, without using a formula, whether B = A^-1.
Compute AB and BA and relate the result to the definition of the inverse.

## Solution

AB = [2*1 + 1*(-1), 2*(-1) + 1*2; 1*1 + 1*(-1), 1*(-1) + 1*2] = [1, 0; 0, 1] = I
BA = [1*2 + (-1)*1, 1*1 + (-1)*1; -1*2 + 2*1, -1*1 + 2*1] = [1, 0; 0, 1] = I

AB = BA = I, so B = A^-1.
