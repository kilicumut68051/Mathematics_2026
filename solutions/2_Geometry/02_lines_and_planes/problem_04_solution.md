## Question

Find the equation of the plane through

$$
A=(1,0,0),\quad B=(0,1,0),\quad C=(0,0,1).
$$

First construct two vectors lying in the plane, and then use the cross product. Check the resulting equation on all three points.

## Solution

$\overrightarrow{AB} = (-1, 1, 0)$, $\overrightarrow{AC} = (-1, 0, 1)$
$\mathbf{n} = \overrightarrow{AB} \times \overrightarrow{AC} = (1, 1, 1)$
Equation: $1(x - 1) + 1(y - 0) + 1(z - 0) = 0 \implies x + y + z = 1$
Check $A(1, 0, 0)$: $1 + 0 + 0 = 1$
Check $B(0, 1, 0)$: $0 + 1 + 0 = 1$
Check $C(0, 0, 1)$: $0 + 0 + 1 = 1$
