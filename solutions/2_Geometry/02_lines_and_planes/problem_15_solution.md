1) One intersection point: v . n != 0. Example: p = (0, 0, 0), v = (1, 0, 0), n = (1, 0, 0), d = 2 => t = 2, point (2, 0, 0).
2) Parallel with no common points: v . n = 0 and p . n != d. Example: p = (0, 0, 0), v = (1, 0, 0), n = (0, 0, 1), d = 1.
3) Line contained in the plane: v . n = 0 and p . n = d. Example: p = (0, 0, 1), v = (1, 0, 0), n = (0, 0, 1), d = 1.
