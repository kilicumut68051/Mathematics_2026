## Question

Given

$$
L:(x,y,z)=(2,-1,3)+t(1,2,-2).
$$

State a point on the line and its direction vector, check whether $P=(4,3,-1)$ lies on $L$, and find the point corresponding to $t=-1$.

## Solution

Point on $L$: $(2, -1, 3)$
Direction vector: $(1, 2, -2)$
Check $P(4, 3, -1)$: $2 + t = 4 \Rightarrow t = 2$; $-1 + 2(2) = 3$; $3 - 2(2) = -1 \Rightarrow$ Yes, $P$ lies on $L$ ($t = 2$).
For $t = -1$: $(2 - 1, -1 - 2, 3 + 2) = (1, -3, 5)$
